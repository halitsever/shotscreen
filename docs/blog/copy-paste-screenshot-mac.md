# Copy a screenshot on Mac and paste it anywhere

<p class="post-meta">By <a href="https://halit.org">Halit Sever</a> · <time datetime="2026-11-28">28 November 2026</time></p>

<p class="lead">A Mac saves screenshots as files on the desktop by default. When you only want to paste the image into a chat, an email or a document, add the Control key to the shortcut and the screenshot goes to the clipboard instead, with no file left behind.</p>

## Screenshot to the clipboard

| Shortcut | Copies |
| --- | --- |
| <kbd>Control</kbd> <kbd>Shift</kbd> <kbd>Command</kbd> <kbd>3</kbd> | The entire screen |
| <kbd>Control</kbd> <kbd>Shift</kbd> <kbd>Command</kbd> <kbd>4</kbd>, then drag | The selected area |
| <kbd>Control</kbd> <kbd>Shift</kbd> <kbd>Command</kbd> <kbd>4</kbd>, then <kbd>Space</kbd>, then click | One window |

Then click where the image should go and press <kbd>Command</kbd> <kbd>V</kbd> to paste it. This works in Mail, Messages, Notes, Pages, Slack, Google Docs in a browser and most other apps that accept images. The clipboard holds one thing at a time, so the next copy replaces the screenshot.

The macOS steps here were checked against Apple's [macOS User Guide](https://support.apple.com/guide/mac-help/take-screenshots-or-screen-recordings-mh26782/mac) for macOS 27 Golden Gate and [Apple's screenshot guide](https://support.apple.com/en-us/102646) in November 2026. They have worked the same way since macOS Mojave unless noted.

## Make the clipboard the default

If you almost never want the files, change where the shortcuts save:

1. Press <kbd>Shift</kbd> <kbd>Command</kbd> <kbd>5</kbd> to open the Screenshot app.
2. Click **Options**.
3. Under **Save to**, choose **Clipboard**.

From now on <kbd>Shift</kbd> <kbd>Command</kbd> <kbd>3</kbd> and <kbd>Shift</kbd> <kbd>Command</kbd> <kbd>4</kbd> copy instead of saving, without holding Control. Choose **Desktop** again to go back.

## Copy a screenshot you already took

- **While the thumbnail is showing**, Control-click it and choose **Save to Clipboard**. You can also drag the thumbnail straight into the window where you want the image.
- **From a saved file**, select it in Finder and press <kbd>Command</kbd> <kbd>C</kbd>. Most apps that accept images paste the picture; a few paste the file instead. To be sure you copy the pixels, open the file in Preview, press <kbd>Command</kbd> <kbd>A</kbd> to select all and then <kbd>Command</kbd> <kbd>C</kbd>.

## When paste does not work

- **The app does not accept images.** Plain text fields, such as a Terminal window or a code editor set to plain text, cannot take a picture. Paste into Preview with **File › New from Clipboard** to check that the image is really on the clipboard.
- **You pressed the shortcut without Control.** The screenshot went to a file instead. Look on the desktop or in the folder set under **Save to**, as described in [where screenshots go on Mac](/blog/where-do-screenshots-go-on-mac).
- **Something else was copied afterwards.** Take the screenshot again.

## Website screenshots

[Shotscreen Browser](/) saves every website capture as a file, because it is built for clean PNGs you keep and reuse. Its history panel (the clock icon) has a button that copies a shot's file path, which you can paste into a terminal, a script or a file dialog.

## FAQ

### How do I copy a screenshot to the clipboard on a Mac?

Add Control to the shortcut: Control-Shift-Command-3 for the whole screen or Control-Shift-Command-4 for an area. Then paste with Command-V.

### Where is the clipboard on a Mac?

It has no window of its own. In Finder, Edit › Show Clipboard shows what is on it, and Preview's File › New from Clipboard opens a copied image.

### Can I stop Mac screenshots from saving files?

Yes. In the Screenshot app (Shift-Command-5), open Options and choose Clipboard under Save to. The shortcuts then copy instead of saving.
