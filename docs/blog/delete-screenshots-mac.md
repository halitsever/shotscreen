# Delete screenshots on a Mac and keep the desktop clear

<p class="post-meta">By <a href="https://halit.org">Halit Sever</a> · <time datetime="2026-11-28">28 November 2026</time></p>

<p class="lead">Screenshots pile up because each one is saved as its own file, and by default they all land on the desktop. You can delete them one at a time, find and remove all of them in one go, or change the setting so they stop collecting there.</p>

## Delete a screenshot you just took

While the floating thumbnail is in the corner, click it to open the preview window. There is a **Delete** button (a trash can) in that window. If the thumbnail is already gone, the file is saved, so delete it in Finder as below.

The macOS steps here were checked against Apple's [macOS User Guide](https://support.apple.com/guide/mac-help/take-screenshots-or-screen-recordings-mh26782/mac) for macOS 27 Golden Gate and [Apple's screenshot guide](https://support.apple.com/en-us/102646) in November 2026. They have worked the same way since macOS Mojave unless noted.

## Delete one screenshot in Finder

Select the file on the desktop or in Finder and press <kbd>Command</kbd> <kbd>Delete</kbd>, or drag it to the Trash. It stays in the Trash until you empty it, so you can still put it back.

## Find and delete every screenshot

1. Open a Finder window and press <kbd>Command</kbd> <kbd>F</kbd> to start a search.
2. Choose **This Mac** to search everywhere, or the folder where your screenshots are saved.
3. Type `Screenshot` in the search field and choose **Name matches: Screenshot**. Every screenshot's file name begins with that word.
4. Check the list, select the files you want to remove (<kbd>Command</kbd> <kbd>A</kbd> selects all) and press <kbd>Command</kbd> <kbd>Delete</kbd>.

Look before you delete everything: other files can also have "Screenshot" in their name. Empty the Trash when you are sure.

## Group them with Stacks first

If your screenshots are on the desktop, click the desktop and choose **View › Use Stacks**. macOS gathers them into a single **Screenshots** stack, which you can open and clear in one place.

## Stop them from collecting on the desktop

- **Save somewhere else.** Press <kbd>Shift</kbd> <kbd>Command</kbd> <kbd>5</kbd>, click **Options**, and under **Save to** choose **Other Location** and pick a folder, such as a Screenshots folder in Pictures. The same menu has **Clipboard**, which saves no file at all.
- **Copy instead of saving.** Add <kbd>Control</kbd> to the shortcut when you only need to paste the image somewhere. See [copy and paste a screenshot on Mac](/blog/copy-paste-screenshot-mac).

[Where screenshots go on Mac](/blog/where-do-screenshots-go-on-mac) covers the save location in more detail, including a Terminal command.

## Shotscreen's shot history

[Shotscreen Browser](/) keeps a list of the website shots taken since the app was opened, behind the clock icon. The trash button at the top of that list clears the list only. The PNG files stay wherever you saved them, so delete those in Finder like any other file.

## FAQ

### How do I delete all screenshots on my Mac at once?

Search Finder with Command-F for files whose name matches Screenshot, select the results and press Command-Delete. Check the list first, then empty the Trash.

### Can I delete a screenshot right after taking it?

Yes. Click the floating thumbnail and use the Delete button in the window that opens.

### How do I stop screenshots saving to my desktop?

Press Shift-Command-5, click Options and choose another folder or Clipboard under Save to.
