# How to crop a screenshot on Mac

<p class="post-meta">By <a href="https://halit.org">Halit Sever</a> · <time datetime="2026-11-28">28 November 2026</time></p>

<p class="lead">macOS can crop a screenshot in three places without any extra app: the floating thumbnail that appears right after the shot, Preview, and Photos. The fastest is the thumbnail. The best crop of all is the one you never have to do.</p>

## 1. Right after the shot: the floating thumbnail

1. Take the screenshot. A thumbnail appears in the bottom-right corner.
2. Click the thumbnail. It opens in a Markup window.
3. Click the **Crop** button in the toolbar. Handles appear on the edges.
4. Drag the handles to the area you want to keep.
5. Click **Done**. The cropped image is saved in place of the original.

The thumbnail only stays for a few seconds. If it is gone, use Preview. If it never shows, it was turned off under **Options › Show Floating Thumbnail** in the Screenshot app (<kbd>Shift</kbd> <kbd>Command</kbd> <kbd>5</kbd>).

The macOS steps here were checked against Apple's [macOS User Guide](https://support.apple.com/guide/mac-help/take-screenshots-or-screen-recordings-mh26782/mac) for macOS 27 Golden Gate and [Apple's screenshot guide](https://support.apple.com/en-us/102646) in November 2026. They have worked the same way since macOS Mojave unless noted.

## 2. Any time: Preview

1. Double-click the screenshot. It opens in Preview.
2. Drag over the part you want to keep. If dragging does not draw a box, choose **Tools › Rectangular Selection** first.
3. Choose **Tools › Crop**, or press <kbd>Command</kbd> <kbd>K</kbd>.
4. Save with <kbd>Command</kbd> <kbd>S</kbd>.

Preview changes the file itself. To keep the original, use **File › Duplicate** before cropping. **Tools › Adjust Size** sets an exact width and height in pixels after the crop.

## 3. In your library: Photos

If the screenshot is in Photos, open it, click **Edit**, then **Crop**. Drag the corners, or pick a fixed ratio such as square or 16:9 from the aspect menu. Click **Done**. Photos keeps the original, so **Revert to Original** undoes the crop later.

## Skip the crop: capture the right area

- <kbd>Shift</kbd> <kbd>Command</kbd> <kbd>4</kbd> and drag captures only the selected area, which is a crop made before the shot. Hold <kbd>Space</kbd> while dragging to move the box.
- <kbd>Shift</kbd> <kbd>Command</kbd> <kbd>4</kbd>, then <kbd>Space</kbd>, captures one window and nothing around it.
- In the Screenshot app, **Options › Remember Last Selection** reuses the same box, so a series of shots all have the same size.

## Website screenshots without cropping

The usual reason to crop a screenshot of a web page is to remove the browser: tabs, address bar, bookmarks and the window frame. Then you have to crop it again to the size the image is meant for, such as a phone mockup or a slide.

[Shotscreen Browser](/) avoids both crops. It is a frameless browser, so there is no browser interface in the capture, and the viewport menu sets the page to an exact size before you press <kbd>Command</kbd> <kbd>Shift</kbd> <kbd>S</kbd>:

| Preset | Size |
| --- | --- |
| iPhone 15 | 393 x 852 |
| iPad | 820 x 1180 |
| MacBook Air | 1280 x 800 |
| Desktop | 1440 x 900 |
| Ultrawide | 1920 x 1080 |

A custom width and height can be typed in too. More on the presets is in the [guide](/#viewport).

## FAQ

### What is the shortcut to crop on a Mac?

In Preview, select an area and press Command-K. That runs Tools, Crop.

### Can I undo a crop in Preview?

Before closing the file, choose Edit, Undo or File, Revert To. After that the crop is permanent, so duplicate the file first if you need the original.
