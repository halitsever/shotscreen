# Every screenshot shortcut on a Mac, and what each one captures

<p class="post-meta">By <a href="https://halit.org">Halit Sever</a> · <time datetime="2026-11-28">28 November 2026</time></p>

<p class="lead">A Mac has no Print Screen key. Screenshots come from three key combinations built on Shift and Command, plus a fourth that opens the Screenshot app. Add Control to any of them and the image goes to the clipboard instead of a file.</p>

## The shortcuts

| Shortcut | What it captures | Where it goes |
| --- | --- | --- |
| <kbd>Shift</kbd> <kbd>Command</kbd> <kbd>3</kbd> | The entire screen | A file on the desktop |
| <kbd>Shift</kbd> <kbd>Command</kbd> <kbd>4</kbd>, then drag | The area you select | A file on the desktop |
| <kbd>Shift</kbd> <kbd>Command</kbd> <kbd>4</kbd>, then <kbd>Space</kbd>, then click | One window or the menu bar | A file on the desktop |
| <kbd>Shift</kbd> <kbd>Command</kbd> <kbd>5</kbd> | Opens the Screenshot app with every option | The location set in Options |
| <kbd>Shift</kbd> <kbd>Command</kbd> <kbd>6</kbd> | The Touch Bar, on Macs that have one | A file on the desktop |
| <kbd>Control</kbd> plus any of the above | The same area | The clipboard only |

Press the keys together and let go. Screenshots are saved as PNG files whose names start with "Screenshot" and include the date and time.

The macOS steps here were checked against Apple's [macOS User Guide](https://support.apple.com/guide/mac-help/take-screenshots-or-screen-recordings-mh26782/mac) for macOS 27 Golden Gate and [Apple's screenshot guide](https://support.apple.com/en-us/102646) in November 2026. They have worked the same way since macOS Mojave unless noted.

## Selecting an area: Shift-Command-4

The pointer turns into a crosshair. Drag over the area you want and let go of the mouse or trackpad to take the shot.

- Hold <kbd>Space</kbd> while dragging to move the selection instead of resizing it.
- Press <kbd>Esc</kbd> to cancel.

## One window: Shift-Command-4, then Space

After <kbd>Space</kbd> the crosshair becomes a camera and the window under it is highlighted. Click to capture that window, with its shadow. To leave the shadow out, hold <kbd>Option</kbd> while you click.

## The Screenshot app: Shift-Command-5

This opens a toolbar at the bottom of the screen with buttons to capture the entire screen, a window or a portion, and to record the screen. The **Options** menu sets where files are saved, a timer, whether the floating thumbnail appears, whether the last selection is remembered and whether the pointer is shown. The Screenshot app has been part of macOS since Mojave. Recording is covered in a separate guide on [how to stop a screen recording on Mac](https://projects.halit.org/avora-screen-recorder/blog/how-to-stop-screen-recording-on-mac).

## Copy to the clipboard instead of saving

Hold <kbd>Control</kbd> with any shortcut: <kbd>Control</kbd> <kbd>Shift</kbd> <kbd>Command</kbd> <kbd>3</kbd> copies the whole screen, <kbd>Control</kbd> <kbd>Shift</kbd> <kbd>Command</kbd> <kbd>4</kbd> copies a selection. Nothing lands on the desktop. Paste with <kbd>Command</kbd> <kbd>V</kbd> into a chat, an email or a document. This is the closest match to the Print Screen key on Windows.

## Change the shortcuts

Open **System Settings › Keyboard › Keyboard Shortcuts** and choose **Screenshots**. Each action can be turned off or given a new key combination. That is also how to put screenshots on a single key, such as F13 on an extended keyboard.

## The floating thumbnail

After a shot, a thumbnail appears in the corner of the screen for a few seconds. Click it to mark up or [crop the screenshot](/blog/how-to-crop-a-screenshot-on-mac), drag it straight into another app, or ignore it and the file is saved. While it is showing, the file is not on the desktop yet. Turn it off in the Screenshot app under **Options › Show Floating Thumbnail** if you want files saved at once. Where the files end up, and how to change it, is in [where do screenshots go on Mac](/blog/where-do-screenshots-go-on-mac).

## Screenshots of websites

The shortcuts capture whatever is on screen, so a screenshot of a web page also includes the browser's tabs, address bar and window frame, or you crop them out by hand. [Shotscreen Browser](/) is a free, frameless browser made for this one job. You type a URL, pick a viewport size such as iPhone 15 (393 x 852) or MacBook Air (1280 x 800), and press <kbd>Command</kbd> <kbd>Shift</kbd> <kbd>S</kbd>. The saved image holds only the page, at that size, with optional rounded corners. It can also capture the [full height of the page](/blog/full-page-screenshot-mac) in one image.

## FAQ

### What is the shortcut for a screenshot on a Mac?

Shift-Command-3 captures the entire screen, Shift-Command-4 a selected area, and Shift-Command-5 opens the Screenshot app. Add Control to copy to the clipboard instead.

### How do I screenshot only one window on a Mac?

Press Shift-Command-4, then Space, then click the window. Hold Option while clicking to leave out the window's shadow.

### Can I change the Mac screenshot shortcut?

Yes. Go to System Settings, Keyboard, Keyboard Shortcuts, Screenshots and set new keys for each action.
