# How to print screen on a Mac

<p class="post-meta">By <a href="https://halit.org">Halit Sever</a> · <time datetime="2026-11-28">28 November 2026</time></p>

<p class="lead">Mac keyboards have no Print Screen key. The same job is done with a few shortcuts, and one of them behaves exactly like Print Screen on Windows by copying the screen to the clipboard. If you meant printing a screenshot on paper, that is at the end.</p>

## The Print Screen equivalents

| On Windows | On a Mac |
| --- | --- |
| <kbd>PrtScn</kbd>: copy the screen to the clipboard | <kbd>Control</kbd> <kbd>Shift</kbd> <kbd>Command</kbd> <kbd>3</kbd> |
| <kbd>Alt</kbd> <kbd>PrtScn</kbd>: copy the active window | <kbd>Control</kbd> <kbd>Shift</kbd> <kbd>Command</kbd> <kbd>4</kbd>, then <kbd>Space</kbd>, then click the window |
| <kbd>Windows</kbd> <kbd>Shift</kbd> <kbd>S</kbd>: snip an area | <kbd>Shift</kbd> <kbd>Command</kbd> <kbd>4</kbd>, then drag (add <kbd>Control</kbd> to copy) |
| Save the whole screen to a file | <kbd>Shift</kbd> <kbd>Command</kbd> <kbd>3</kbd> |
| Snipping Tool | The Screenshot app: <kbd>Shift</kbd> <kbd>Command</kbd> <kbd>5</kbd> |

<kbd>Shift</kbd> <kbd>Command</kbd> <kbd>3</kbd> captures the entire screen, and <kbd>Shift</kbd> <kbd>Command</kbd> <kbd>4</kbd> lets you select the area you want, a portion of the screen. Without <kbd>Control</kbd>, the screenshot is saved as a PNG file on the desktop. With it, nothing is saved and you paste the image with <kbd>Command</kbd> <kbd>V</kbd>. The full list is in [Mac screenshot shortcuts](/blog/mac-screenshot-shortcuts).

The macOS steps here were checked against Apple's [macOS User Guide](https://support.apple.com/guide/mac-help/take-screenshots-or-screen-recordings-mh26782/mac) for macOS 27 Golden Gate and [Apple's screenshot guide](https://support.apple.com/en-us/102646) in November 2026. They have worked the same way since macOS Mojave unless noted.

## What happened to Grab?

Older Macs had an app called Grab in **Applications › Utilities**. macOS Mojave replaced it with the Screenshot app, which sits in the same Utilities folder and opens with <kbd>Shift</kbd> <kbd>Command</kbd> <kbd>5</kbd>. It does what Grab did, including timed screenshots (**Options › Timer**), and adds screen recording.

## Use a Print Screen key anyway

On a PC keyboard connected to a Mac, or a keyboard with spare function keys, you can assign a key yourself:

1. Open **System Settings › Keyboard › Keyboard Shortcuts**.
2. Choose **Screenshots**.
3. Double-click the shortcut next to an action, such as **Copy picture of screen to the clipboard**, and press the key you want, for example F13.

## How to print a screenshot on Mac

1. Double-click the screenshot to open it in Preview.
2. Choose **File › Print**, or press <kbd>Command</kbd> <kbd>P</kbd>.
3. Under **Scale**, choose to fit the page if the screenshot is larger than the paper, then click **Print**.

To go straight to Preview without finding the file, open the Screenshot app, click **Options** and choose **Preview** under **Save to**. Each new screenshot then opens in Preview, ready to print. Turn it back to **Desktop** afterwards. If the printout looks rough, see [higher resolution screenshots](/blog/higher-resolution-screenshot-mac).

## Printing a web page as an image

To print or save a whole web page, a screenshot of the screen only gets the visible part. [Shotscreen Browser](/) captures a page's full height in one PNG, without the browser's own toolbars, which you can then print from Preview. The [full page guide](/blog/full-page-screenshot-mac) compares it with the browsers' own tools.

## FAQ

### What is Print Screen on a Mac?

Control-Shift-Command-3 copies the whole screen to the clipboard, like PrtScn on Windows. Shift-Command-3 saves it as a file instead.

### Where is the Grab app on Mac?

Grab was replaced by the Screenshot app in macOS Mojave. It is in Applications, Utilities, and opens with Shift-Command-5.
