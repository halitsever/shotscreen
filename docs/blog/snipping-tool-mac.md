# Is there a Snipping Tool on Mac?

<p class="post-meta">By <a href="https://halit.org">Halit Sever</a> · <time datetime="2026-11-28">28 November 2026</time></p>

<p class="lead">Snipping Tool is a Windows app, so you will not find it on a Mac. You do not need to install anything to replace it, though: macOS has its own Screenshot app and a set of shortcuts that cover every Snipping Tool mode except free-form.</p>

## The Mac version of Snipping Tool

On Windows, <kbd>Windows</kbd> <kbd>Shift</kbd> <kbd>S</kbd> opens the Snipping Tool overlay. On a Mac, the closest match is <kbd>Shift</kbd> <kbd>Command</kbd> <kbd>5</kbd>, which opens the **Screenshot** app with a toolbar at the bottom of the screen. From there you pick the whole screen, a window or a selected portion, and set a timer or the save location under **Options**. You can also open Screenshot from Spotlight, or from the Utilities folder inside Applications.

The macOS steps here were checked against Apple's [macOS User Guide](https://support.apple.com/guide/mac-help/take-screenshots-or-screen-recordings-mh26782/mac) for macOS 27 Golden Gate and [Apple's screenshot guide](https://support.apple.com/en-us/102646) in November 2026. They have worked the same way since macOS Mojave unless noted.

## Snipping Tool modes and their Mac equivalents

| Snipping Tool (Windows 11) | On a Mac |
| --- | --- |
| Rectangle snip | <kbd>Shift</kbd> <kbd>Command</kbd> <kbd>4</kbd>, then drag over the area |
| Window snip | <kbd>Shift</kbd> <kbd>Command</kbd> <kbd>4</kbd>, then <kbd>Space</kbd>, then click the window |
| Full screen snip | <kbd>Shift</kbd> <kbd>Command</kbd> <kbd>3</kbd> |
| Free-form snip | No built-in equivalent. Take a rectangle and crop it |
| Delay | Screenshot app, **Options › Timer** |
| Copy to clipboard (<kbd>Ctrl</kbd> <kbd>C</kbd>) | Add <kbd>Control</kbd> to any shortcut |
| Annotate after the snip | Click the floating thumbnail and use Markup |
| Video snip | Screenshot app, **Record Selected Portion** |

The Windows side is from Microsoft's [Snipping Tool guide](https://support.microsoft.com/en-us/windows/use-snipping-tool-to-capture-screenshots-00246869-1843-655f-f220-97299b865f6b). The free-form mode is the only one without a Mac counterpart.

## Mark up a screenshot like in Snipping Tool

After a capture, a thumbnail floats in the bottom-right corner of the screen for a few seconds. Click it to open a window where you can draw, add text and shapes, crop, or share the image. Swipe it to the right to save at once, or drag it straight into a document, an email or a Finder window. If no thumbnail appears, turn on **Show Floating Thumbnail** in the Screenshot app's **Options** menu.

## Change the shortcut

If you are used to <kbd>Windows</kbd> <kbd>Shift</kbd> <kbd>S</kbd>, you can move the Mac shortcuts closer to it. Open **Apple menu › System Settings › Keyboard**, click **Keyboard Shortcuts**, choose **Screenshots** and double-click a shortcut to type a new one. The full list of default keys is in [Mac screenshot shortcuts](/blog/mac-screenshot-shortcuts).

## For screenshots of websites

Snipping a browser window always brings the browser along: tabs, the address bar, sometimes a cookie banner. [Shotscreen Browser](/) is a free Mac app made for this one job. It shows the page in a frameless window at a fixed size (iPhone 15, iPad, MacBook Air, Desktop, Ultrawide or your own), hides most cookie banners, and saves a PNG of either the visible area or the whole page when you press <kbd>Command</kbd> <kbd>Shift</kbd> <kbd>S</kbd>.

## FAQ

### Does Mac have a Snipping Tool?

No. Snipping Tool is a Windows app. The Mac equivalent is the built-in Screenshot app, opened with Shift-Command-5, plus the Shift-Command-3 and Shift-Command-4 shortcuts.

### What is the Mac shortcut for Snipping Tool?

Shift-Command-4 lets you drag over an area, like a rectangle snip. Shift-Command-5 opens the Screenshot app with every option, which is closest to the Snipping Tool overlay.

### Can I snip a free-form shape on a Mac?

Not with the built-in tools. Capture a rectangle with Shift-Command-4 and crop or mark it up afterwards.
